# Context Registry — Optional Project Template

This is an **optional template**, not a DLD requirement or an authoritative registry until adopted and maintained by a project.

Recommended convention: copy this file to `CONTEXT-REGISTRY.md` at your **project root**, alongside the unchanged `dld/` directory. Paths below are relative to that project root. Adapt, replace, or omit this convention when another means makes governing context discoverable.

## Adopted foundation

| Source (project-root relative) | Responsibility |
| --- | --- |
| `dld/CONTRACT.md` | Adopted human–AI collaboration foundation |
| `dld/DLD.md` | Adopted design-led engineering methodology |
| `dld/VERSION` | Authoritative version of installed DLD |
| `dld/supporting/` | Optional guidance, not binding project rules |

## Project-owned context
