# Design-Led Development (DLD)

DLD is a design-centered, human-authoritative, AI-assisted software engineering methodology. Its normative method specification is the `starter/foundation/CORE.md`.

## Adopt DLD

1. Copy the contents of `starter/` into an adopting project (or reconcile with its existing files).
2. Fill in the project README and draft `foundation/DESIGN.md`. Keep the adopted Core unchanged.
3. Approve consequential design decisions before realization; record additional approved project rules in foundation/RULES.md when needed.
4. For AI-assisted work, begin with the project foundation, then load relevant design scopes and evidence progressively.

The starter is complete for DLD's required project foundation. The optional `supporting/repository-layout.md` suggests how to extend project structure and may be copied to `docs/dld/` in an adopting project.
